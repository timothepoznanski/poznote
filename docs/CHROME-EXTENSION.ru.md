# Расширение Poznote для Chrome

**Poznote URL Saver** это расширение браузера, которое одним щелчком сохраняет текущую страницу в ваш экземпляр Poznote: ее адрес, отдельно или вместе со снимком экрана, в новую заметку или в конец уже существующей.

<p align="center">
  <img src="../images/chrome-extension.png" alt="Poznote Chrome Extension" width="50%">
</p>

Установите расширение прямо из Chrome Web Store: [Установить расширение](https://chromewebstore.google.com/detail/bmjclfamahegmgillaghhmnbkjebipbh?utm_source=item-share-cb)

## Подключение к вашему экземпляру

1. В Poznote откройте **Настройки > Пароли приложений**, создайте пароль с названием расширения и скопируйте показанный секрет. Он отображается один раз.
2. Нажмите на значок расширения, затем на **Connect**. Страница настроек откроется во вкладке.
3. Укажите **Poznote address** (например, `https://notes.example.com`), ваш **Username** и только что скопированный **App password**, нажмите **Connect** и разрешите расширению доступ к вашему экземпляру, когда Chrome спросит.
4. Выберите **Workspace** и, при желании, **Folder**, куда должны попадать новые заметки. Выбор сохраняется сразу.

Чтобы изменить эти настройки позже, нажмите на шестеренку в верхней части расширения.

Адрес вашего экземпляра рядом с ней является ссылкой: нажмите на него, чтобы открыть Poznote в новой вкладке, по http или https, как вы указали его в настройках.

Расширение использует язык Chrome, если это английский, французский, немецкий, испанский, португальский, русский, корейский, упрощённый китайский, японский или каталанский, а в остальных случаях английский.

Пароль учетной записи здесь тоже подходит, но для расширения лучше использовать пароль приложения: он дает доступ только к API, но никогда к веб-интерфейсу или настройкам вашей учетной записи, ограничен вашим собственным профилем, а его отзыв в Poznote отключает расширение, ничего больше не меняя. Полный список ограничений приведен в разделе [Пароли приложений](README.ru.md#пароли-приложений).

> **Если ваш экземпляр работает в режиме «только SSO»,** пароль приложения остается единственным способом подключить расширение: формы входа, которая нужна расширению, для вашей учетной записи не существует. Создайте его в **Настройки > Пароли приложений** точно так же, как описано выше.

## Сохранение страницы

На странице, которую вы хотите сохранить, нажмите на значок расширения и выберите, куда она попадет:

- **New note** создает заметку с названием страницы в рабочем пространстве и папке, выбранных в настройках.
- **Existing note** добавляет страницу в конец заметки, выбранной в списке. Список показывает последние заметки и ищет по ним по мере ввода. В нем видны заметки рабочего пространства, выбранного в настройках; включите **All workspaces**, чтобы выбрать заметку из любого пространства. Расширение запоминает эту заметку для следующей страницы, поэтому собирать ссылки в один список для чтения можно одним щелчком на страницу. Страницы можно добавлять в заметки HTML и Markdown.

Затем нажмите **Save link**, чтобы сохранить адрес страницы, или **Screenshot**, чтобы сохранить адрес и под ним изображение видимой части страницы. В подтверждении есть ссылка, которая открывает заметку в Poznote.
