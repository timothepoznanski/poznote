# Poznote Chrome拡張機能

**Poznote URL Saver**は、表示中のページを1回のクリックでPoznoteインスタンスに保存するブラウザー拡張機能です。ページのアドレスだけ、またはアドレスとスクリーンショットを、新しいノートとして、または既存のノートの末尾に保存できます。

<p align="center">
  <img src="../images/chrome-extension.png" alt="Poznote Chrome拡張機能" width="50%">
</p>

拡張機能は、Chromeウェブストアから直接インストールできます：[拡張機能をインストール](https://chromewebstore.google.com/detail/bmjclfamahegmgillaghhmnbkjebipbh?utm_source=item-share-cb)

## インスタンスへの接続

1. Poznoteで「設定 > マイアカウント > アプリパスワード」を開き、拡張機能用だとわかる名前でアプリパスワードを作成して、表示されたシークレットをコピーします。シークレットは一度しか表示されません。
2. 拡張機能のアイコンをクリックしてから、「接続」を選びます。拡張機能の設定ページがタブで開きます。
3. 「Poznoteのアドレス」（例：`https://notes.example.com`）、「ユーザー名」、コピーしたばかりの「アプリパスワード」を入力して「接続」をクリックします。Chromeに確認されたら、拡張機能がインスタンスにアクセスすることを許可します。
4. 新しいノートの保存先にする「ワークスペース」と、必要に応じて「フォルダー」を選びます。選んだ内容はその場で保存されます。

あとで変更するには、拡張機能の上部にある歯車アイコンをクリックします。

歯車アイコンの横に表示されるインスタンスのアドレスはリンクになっています。クリックすると、新しいタブでPoznoteが開きます。httpとhttpsのどちらで開くかは、設定で入力したとおりです。

拡張機能は、Chromeの表示言語が英語、フランス語、ドイツ語、スペイン語、ポルトガル語、ロシア語、韓国語、簡体字中国語、日本語のいずれかであればその言語で、それ以外の場合は英語で表示されます。

アカウントのパスワードも使えますが、拡張機能にはアプリパスワードのほうが適しています。アプリパスワードでアクセスできるのはAPIだけで、Webインターフェースやアカウントの設定にはアクセスできません。また、自分のプロフィールだけに限られ、Poznoteで取り消せば、ほかには何も変えずに拡張機能だけを切り離せます。制限の一覧は[アプリパスワード](README.ja.md#アプリパスワード)を参照してください。

> **インスタンスがSSO専用の場合**、拡張機能を接続する方法はアプリパスワードしかありません。拡張機能が使うログインフォームが、そのアカウントには存在しないためです。上と同じ手順で、「設定 > マイアカウント > アプリパスワード」から作成してください。

## ページの保存

保存したいページで拡張機能のアイコンをクリックし、保存先を選びます：

- 「新規ノート」は、設定で選んだワークスペースとフォルダーに、ページのタイトルを名前にしたノートを作成します。
- 「既存のノート」は、一覧で選んだノートの末尾にページを追加します。一覧には最近のノートが表示され、入力に合わせて検索されます。一覧に表示されるのは、設定で選んだワークスペースのノートです。どこにあるノートでも選べるようにするには、「すべてのワークスペース」をオンにします。拡張機能は選んだノートを次のページのために記憶しておくので、1つの読書リストにリンクを集めるときも、1ページにつき1回のクリックで済みます。ページを追加できるのは、HTMLとMarkdownのノートです。

そのあと、ページのアドレスを保存するには「リンクを保存」を、アドレスに続けてページの表示されている部分の画像を保存するには「スクリーンショット」をクリックします。確認のメッセージには、Poznoteでノートを開くリンクが表示されます。
